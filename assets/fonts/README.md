# IBM Plex Mono

Unmodified Regular (400) and Medium (500), bundled for offline UI labels and
headings. Conversation text retains the platform's sans-serif font. No runtime
font service or extra Flutter dependency is used.

Source: [Google Fonts, pinned revision](https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/ibmplexmono).
License: SIL Open Font License 1.1, included in `OFL.txt` and the app bundle.
